Quickstart

Trace your first agent run

Bindle records every step your agent takes — LLM calls, tool calls, retrievals, decisions and handoffs — in one trace. Add one line, run your agent, and open the console.

1

Install the SDK

pip install bindle-sdk            # core
pip install 'bindle-sdk[all]'     # + framework auto-instrumentation
2

Initialise it

import bindle

bindle.init(agent="support-triage", version="v12")
# reads BINDLE_API_KEY and BINDLE_ENDPOINT

Python 3.9+. Installed frameworks are detected and instrumented automatically.

1

Install the SDK

npm install @bindle-ai/sdk
2

Initialise it

import * as bindle from '@bindle-ai/sdk';

bindle.init({ agent: 'support-triage', version: 'v12', environment: 'prod' });

Node.js 20+. Without a key, init() warns once and does nothing.

3

Run your agent and open the console

Every step lands in one trace. Open Runs to see the summary, the waterfall and the root-cause step selected for you.

Safe to commit: without BINDLE_API_KEY the SDK is a no-op. Prefer the environment variable over a key in code.

Run the local stack

Needs Docker, Go 1.25+, Node 20+ and Python 3.9+. Go dependencies are downloaded at build time; on networks that block proxy.golang.org, set GOPROXY=direct.

git clone https://github.com/varun7447/bindle
cd bindle
make up          # OpenSearch, PostgreSQL, ingest, API, alerts
make console     # console at http://localhost:3000
make demo        # demo runs, including a runaway loop

Point an agent at it

set -a; . deploy/local/.env; set +a    # BINDLE_API_KEY and BINDLE_ENDPOINT
pip install -e sdks/python
python examples/sdk/quickstart.py

Instrument your agent

Installed frameworks — LangGraph, Strands, Google ADK, Microsoft Agent Framework, Amazon Bedrock AgentCore — are detected and instrumented automatically. For custom agent code, mark tools and steps yourself:

@bindle.trace_tool
def lookup_customer(email: str) -> dict: ...

@bindle.trace_step(type="retrieval")
async def search_kb(query: str): ...

bindle.decision("route", options=["crm", "kb", "human"],
                chosen="crm", rationale="needs account data")
bindle.handoff("human-escalation", reason="eval score below threshold")

with bindle.step("plan", type="decision"):
    ...
Serverless? Call bindle.flush() before your handler returns.

Configuration

Every option can be passed to init() or set as an environment variable. No config file needed.

Env varDefaultMeaning
BINDLE_API_KEY(none)Ingest key. Without it the SDK is a no-op.
BINDLE_ENDPOINT(none)Your Bindle ingest URL. Without it the SDK is a no-op.
BINDLE_AGENT / _VERSION(none)Agent name and version
BINDLE_ENVIRONMENT(none)e.g. prod, staging
BINDLE_SAMPLE_RATE1.0Head sampling, 0–1
BINDLE_REDACTtrueRedact PII and secrets before export
BINDLE_CAPTURE_CONTENTtrueSend prompts and outputs at all
BINDLE_AUTO_INSTRUMENTtrueDetect and instrument frameworks
BINDLE_REMOTE_CONFIGtrueFetch sampling, capture and redaction settings from the console

Remote settings

Sample rate, content capture and extra redaction patterns can be changed from the console without a redeploy; agents pick them up within two minutes. The console sets a ceiling — your code can only be stricter.

SDK API

The same surface exists in TypeScript with camelCase names (traceTool, withSession, checkLimits).

CallWhat it does
init()Start tracing. No-op without an API key.
@trace_tool / @trace_stepRecord a function as a tool call or a typed step (retrieval, decision…).
step(name, type=)Context manager for a custom step.
decision() / handoff()Record a routing decision with options and rationale, or a handoff.
set_session(id)Group runs into one conversation.
current_trace_id()The current run’s trace ID, for feedback or scores sent later.
feedback()User thumbs, ratings and comments for a run.
score(name, value)Record a score inside a run or later with trace_id.
outcome(name, success=)Mark whether a run did its job, for cost per successful outcome.
context_token() / resume()Link runs across queues, approvals and handoffs.
inject_mcp_meta() / mcp_server_context()Carry the trace through MCP params._meta.
check_limits()Raise LimitExceeded when paused, over budget, stopped or over a cap.
CassetteReplay a downloaded run with every tool answered from the recording.
flush()Export pending spans — call before a serverless handler returns.

CLI and MCP

bindle init      # detect the framework, save the key to .env,
                 # send a test trace, print the code to add
bindle check     # verify the key and endpoint (sends nothing)
bindle eval      # run a dataset in CI, exit 1 on a drop

bindle init asks for the key with hidden input, writes .env readable only by you, adds it to .gitignore, and never prints the full key.

Let a coding agent set it up

bindle mcp runs an MCP server on stdio with setup-guide, framework-detection, connection-check and test-trace tools. The key is read from the environment and never returned to the model.

claude mcp add bindle -- bindle mcp

Deploy to AWS

deploy/aws/ is an AWS CDK stack: ingest, a private API, the console behind HTTPS with Cognito sign-in, and the data stores, all on ARM (Graviton) Fargate tasks. On AWS, ingest buffers through Kinesis and bindle-processor writes OpenSearch.

cd deploy/aws
cdk deploy                       # Docker must be running
cdk deploy -c goproxy=direct     # if proxy.golang.org is blocked
Deploying creates paid AWS resources.

Optional pieces

deploy/otel-collector/ — an OpenTelemetry Collector config for regulated tenants. deploy/connectors/cloudwatch-spans/ — forwards AWS service spans (AgentCore Gateway, Policy, Identity) from CloudWatch to Bindle.
